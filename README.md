# Автоматизированное тестирование API

## Цели проекта

Цель проекта — проверить функциональность REST API на сайтах [rickandmortyapi.com](https://rickandmortyapi.com)
и [reqres.in](https://reqres.in).

## Структура проекта

Структура проекта организована следующим образом:

- src/main/java/api/models — классы моделей объектов, используемых в тестах.


- src/main/java/api/specifications — класс спецификации для работы с API.


- src/main/java/api/steps — классы шагов для сценариев на Rest Assured.


- src/main/java/cucumberSteps — классы шагов для сценариев на Cucumber.


- src/main/java/utils — вспомогательные утилиты для чтения файлов проекта.


- src/test/java/cucumberTestRunner — классы для запуска тестовых сценариев на Cucumber.


- src/test/java/tests — сценарии тестов для Rest Assured.


- src/test/resources/features — сценарии тестов для Cucumber.


- src/test/resources — файлы настроек тестов и отчетов, а также json-файл, используемый в тестах.

## Технологии, применяемые в проекте

- Java 17
- Maven
- Selenide
- JUnit 5
- Rest Assured
- Allure
- Cucumber
- Google Chrome

## Сценарии тестов:

- Получение последнего эпизода с Морти Смит
- Получение из списка последнего эпизода последнего персонажа
- Получение данных по расе и локации последнего персонажа
- Сравнение расы и локации Морти с последним персонажем
- Создание пользователя на сайте reqres.in.

## Запуск тестов и просмотр отчета

- для запуска тестов необходимо в терминале выполнить команду ```mvn clean test```
- для генерации отчета необходимо в терминале выполнить команду ```mvn allure:report```
- для просмотра отчета в браузере в терминале выполнить команду ```mvn allure:serve```
