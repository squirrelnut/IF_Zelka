# Автоматизированное тестирование системы Jira iFellow

## Цели проекта

Цель проекта — с помощью автотестов проверить функциональность сайта [Jira iFellow](https://edujira.ifellow.ru)

## Структура проекта

Структура проекта организована следующим образом:

- src/main/java/pages — классы Page Object для взаимодействия с элементами сайта.


- src/main/java/utils — конфигурационный класс для настроек проекта.


- src/test/java/pagesTest — сценарии автоматизированных тестов.


- src/test/java/webHooks — класс с методами, запускаемыми до или после каждого теста.


- src/test/resources — файлы для настроек тестов и отчетов по ним.

## Технологии, применяемые в проекте

- Java 17
- Maven
- Selenide
- JUnit 5
- Allure
- Google Chrome

## Сценарии тестов:

- Тест #1. Аутентификация пользователя: проверяется успешная аутентификация и название профиля на главной странице.


- Тест #2. Переход в проект Test: проверяется корректный переход в проект "Test" с проверкой ссылки проекта.


- Тест #3. Проверка количества задач: проверяется увеличение счетчика на единицу после создания новой задачи.


- Тест #4. Проверка задачи TestSeleniumATHomework: проверяется статус и версия задачи TestSeleniumATHomework.


- Тест #5. Создание нового бага: проверяется создание нового баг-репорта и перевод его в финальный статус.

## Запуск тестов и просмотр отчета

- для запуска тестов необходимо в терминале выполнить команду ```mvn clean test```
- для генерации отчета необходимо в терминале выполнить команду ```mvn allure:report```
- для просмотра отчета в браузере в терминале выполнить команду ```mvn allure:serve```
